# Sparky — Autonomous Human Tracking Robot

Sparky is an autonomous mobile robot programmed using Arduino and C to detect and track humans in real time while navigating around obstacles.

## Features

* Real-time human detection and tracking
* Autonomous movement and motor control
* Obstacle detection and avoidance
* Sensor-based navigation
* Arduino-based embedded control system

## Technologies Used

* **Arduino**
* **C/C++**
* **Ultrasonic Sensors**
* **Servo Motor**
* **DC Motors**
* **Motor Driver**

## How It Works

Sparky uses sensors to detect a person and determine their position relative to the robot. The Arduino processes sensor data and controls the motors to follow the detected person.

When an obstacle is detected, the robot adjusts its movement to avoid collisions while continuing to track the target.
